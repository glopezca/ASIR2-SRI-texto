# 🏢 ANEXO XI · Proyecto transversal de Servicios de Red e Internet

## 1. Propósito

Este proyecto integra los aprendizajes de UT1–UT8 en una única infraestructura. El alumnado deja de resolver servicios aislados y pasa a justificar una arquitectura completa.

## 2. Escenario

La organización **JuandeColonia** necesita una red de tamaño medio con estaciones de trabajo, servicios internos y acceso controlado a servicios publicados.

Servicios mínimos:

- direccionamiento y encaminamiento;
- DHCP;
- DNS;
- SFTP;
- web;
- correo + webmail;
- lista de distribución;
- mensajería;
- streaming.

## 4. Entornos

El mismo proyecto puede analizarse con los cuatro entornos, indicando qué aspecto de la arquitectura aporta cada uno.

## 5. Entregables

2. direccionamiento;
3. configuraciones;
4. scripts de prueba;
5. evidencias;
6. análisis de una incidencia;
