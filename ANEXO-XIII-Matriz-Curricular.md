# 🧭 ANEXO XIII · Matriz curricular, evidencias y evaluación

La matriz se utiliza para comprobar que cada resultado de aprendizaje tiene contenido, práctica, evidencia y evaluación asociados.

| RA | UT | Dominio principal | Evidencia de desempeño | Instrumentos |
|---|---|---|---|---|
| RA1 | UT3 | DNS, zonas, resolución, seguridad | Zona validada, consultas, logs y diagnóstico | práctica + test + rúbrica |
| RA2 | UT2 | DHCP, concesiones, relay, seguridad | Concesión comprobada, opciones y captura | práctica + test + rúbrica |
| RA3 | UT5 | HTTP, HTTPS, Virtual Hosts, proxy, logs | Sitio publicado, TLS y diagnóstico | práctica + test + rúbrica |
| RA4 | UT4 | FTP/FTPS/SFTP, permisos | Transferencia segura y control de acceso | práctica + test + rúbrica |
| RA5 | UT6 | SMTP/IMAP/POP3, TLS, autenticación | Envío/recepción, buzón y trazabilidad | práctica + test + rúbrica |
| RA6 | UT7 | XMPP, IRC, listas, NNTP | Sesión o distribución reproducida | práctica + test + rúbrica |
| RA7 | UT8 | Audio, codecs, streaming | Flujo reproducible y parámetros | práctica + test + rúbrica |
| RA8 | UT8 | Vídeo, HLS, RTP, videoconferencia | Reproducción, manifiesto/captura y diagnóstico | práctica + test + rúbrica |

## Competencias transversales

Además del contenido técnico se observa: lectura de logs, línea de comandos, documentación, seguridad, automatización, control de cambios, trabajo reproducible y comunicación de incidencias.

## Niveles de desempeño

| Nivel | Descripción |
|---|---|
| Inicial | Sigue instrucciones y reconoce elementos principales. |
| Operativo | Configura y verifica siguiendo un procedimiento conocido. |
| Diagnóstico | Aísla un fallo con evidencias y modifica una variable cada vez. |
| Profesional | Diseña, justifica, documenta, automatiza parcialmente y propone reversión. |

La matriz es deliberadamente independiente de una herramienta concreta para facilitar la transferencia entre Packet Tracer, WSL, VirtualBox y Compose.
